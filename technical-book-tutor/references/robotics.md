# Robotics / Drone Teaching Mode

Use for drones, robotics, autonomous systems, control, perception, and integration.

```text
  ↓

Controller
  ↓

```

Explain where the excerpt fits.

## Coordinate frames
Make world, body, sensor, camera, and local-frame conventions explicit when relevant.

## Control
Explain desired state, measured state, error, controller, actuator command, and feedback. Show formulas for PID/control concepts.

## Estimation
Explain observations, hidden state, model, measurement, uncertainty, and estimate.

## Real-world constraints
Discuss latency, sensor noise, actuator saturation, sampling rate, timing, power, vibration, and communication delay when relevant.

## Drone examples
Connect to IMU, barometer, GPS, magnetometer, motors/ESCs, PWM, flight controllers, attitude, position, and mission logic when appropriate.

Keep explanations educational and engineering-focused.
