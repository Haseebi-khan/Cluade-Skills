# Mathematics Teaching Mode

Use when the excerpt contains mathematical concepts.

## Teaching order
1. Problem the mathematics solves
2. Intuition
3. Definitions
4. Formula
5. Symbol-by-symbol explanation
6. Plain-English translation
7. Tiny numerical example
8. Derivation if useful
9. Geometric/physical interpretation
10. Assumptions
11. Edge cases
12. Implementation connection

## Formula discipline
Never hide an important formula behind prose. Define symbols, units, dimensions, substitute small numbers, calculate step-by-step, and explain variable sensitivity.

## Derivations
Show meaningful transformations and explain why each is valid. Identify assumptions.

## Sanity checks
When useful check units, sign, magnitude, limiting cases, symmetry, dimensions, and numerical result.

## Mental models
Adapt intuition to calculus, linear algebra, probability, statistics, optimization, discrete mathematics, and numerical methods rather than using generic analogies.
