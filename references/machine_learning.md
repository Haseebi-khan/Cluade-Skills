# Machine Learning Teaching Mode

Use for classical ML, deep learning, PyTorch, TensorFlow/Keras, and research material.

## Core data flow

```text
Data
 ↓
Preprocessing
 ↓
Representation
 ↓
Model
 ↓
Prediction
 ↓
Loss / Objective
 ↓
Gradient
 ↓
Parameter update
 ↓
Evaluation
```

Adapt it to the actual method.

## Tensor discipline
State important tensor shapes and explain why each operation changes them.

## Mathematical connection
Connect objective → loss → gradient → optimizer → parameter update.

## Model comparisons
Compare objective, inductive bias, compute, memory, data requirements, generalization, and inference cost when relevant.

## Practical concerns
Mention leakage, normalization, class imbalance, overfitting, calibration, distribution shift, numerical stability, reproducibility, and GPU memory when relevant.
