# Computer Vision Teaching Mode

Use for digital image processing, classical CV, OpenCV, image formation, CNN vision, and related topics.

## Image-first reasoning
Represent small images as matrices and explain coordinate convention, intensity/channel meaning, dtype, bit depth, and shape.

## Filters/convolution
When a kernel is involved:
1. show kernel,
2. show input patch,
3. multiply corresponding values,
4. sum,
5. explain stride/padding,
6. show output position,
7. repeat for a tiny example.

## Frequency domain
Connect spatial intuition → frequency interpretation → transform → filtering → inverse transform → practical effect.

## Geometry
Explain coordinate system, transformation matrix, mapping, inverse, interpolation, and boundary behavior.

## Implementation
Use NumPy/OpenCV/PyTorch as appropriate. Mention dtype and range issues because they commonly cause silent errors.
