# Quick Mode

Trigger: "I have 10 minutes," "just the essentials," "extract only what I need," or an explicit QUICK/very-tight time budget.

Compress hard. Skip the full metadata block down to one line. Cut straight to:

```markdown
# 🎥 Quick Take: <Video Title>

**In one line:** <what this video teaches>
**Freshness:** <score + one-line caveat, only if something material is outdated — omit if it's all current>

## What You Need to Know (P0 only, plus P1 if it fits the time budget)
1. ...
2. ...
3. ...

## If Anything's Outdated
<original → current, one line each, only for P0/P1 items>

## Try This
<one small, concrete action — not a multi-step mini-mission>

## Next Step
```

Don't include Common Mistakes, full Practice missions, or a multi-question quiz here unless the user asks for more after seeing this — quick mode optimizes for getting the learner moving, not completeness. One quick knowledge-check question is fine if it's genuinely fast to answer.

If the material can't responsibly be compressed this far (e.g. it's genuinely dense, like backprop math or a multi-stage hardware setup), say so directly and offer FAST or STANDARD instead rather than delivering something misleadingly thin.
