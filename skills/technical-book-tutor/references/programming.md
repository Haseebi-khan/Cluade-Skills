# Programming Teaching Mode

Use for Python, C, C++, APIs, algorithms, and implementation-heavy excerpts.

## Teaching sequence
1. Problem
2. Desired behavior
3. Inputs/data
4. Algorithm/logic
5. Formula if applicable
6. Minimal code
7. Walkthrough
8. Expected output
9. Failure modes
10. Complexity
11. Practical improvements
12. Challenge

## Code explanation
For non-trivial lines explain purpose, input, output, type, shape, side effects, and why it is needed.

## Debugging
Teach: reproduce → isolate → inspect inputs/types/shapes/state → minimal reproduction → hypothesis → test → fix → regression test.

## C/C++
Pay attention to ownership, lifetime, stack/heap, pointers/references, const correctness, undefined behavior, resource management, compilation/linking, and performance.

## Python
Pay attention to references, mutability, iterators/generators, NumPy broadcasting, dtype, vectorization, and package/version differences.

Prefer small complete runnable examples.
